# 实践内容、方式与工作量

本实践聚焦于大语言模型后训练阶段的低精度训练问题，重点研究在 FP4 精度下如何提升 DPO/GRPO 等后训练算法的稳定性与可用性。传统后训练方法通常依赖较高精度的前向生成和反向更新过程，而 FP4 低精度虽然能够显著降低计算与存储开销，但也会带来生成分布偏移、奖励信号变弱和训练不稳定等问题，使其难以直接用于强化学习式后训练。

本实践提出的问题核心在于：如何在保持后训练效果的同时，使模型能够适应 FP4 低精度计算环境。为此，我们首先对 GRPO 训练过程中的生成质量进行了分析，发现直接 FP4 后训练容易导致生成结果退化，进而削弱奖励信号并影响策略更新。基于这一观察，本实践从“训练前适配”和“量化过程改进”两个角度展开工作。

在训练前适配方面，我们设计并实现了量化感知自蒸馏方法。该方法使用高精度模型作为教师模型，FP4 模型作为学生模型，通过分布蒸馏约束学生模型对齐教师模型的输出概率分布，使模型在进入 GRPO 后训练前先完成对低精度计算路径的适应。这样可以避免强化学习阶段同时承担任务学习与量化恢复的双重压力，从而提高后续训练的稳定性。

在量化过程改进方面，我们采用移动均值偏差 FP4 方法。该方法不直接对原始激活进行量化，而是先估计激活均值，再对中心化后的残差进行 FP4 量化，最后加回均值项。通过这种方式，FP4 的有限表示范围能够更多用于刻画有效变化部分，从而降低低精度量化带来的信息损失。对于连续生成过程，系统进一步使用移动均值更新机制，使均值估计能够随当前状态动态调整。

本实践还完成了配套的训练诊断与生成质量评估工具。针对 GRPO 后训练依赖生成质量的特点，我们实现了生成质量分析器，对低质量样本比例、重复模式、文本多样性、奖励变化等指标进行记录和可视化，从而将原本主观的生成退化现象转化为可量化的实验依据。同时，实践中对直接 FP4 后训练、量化感知自蒸馏后 FP4 后训练以及高精度后训练基线进行了对比实验，用于分析不同训练方案在奖励、低质量样本比例和训练稳定性方面的差异。

目前实践工作已完成主要算法原型、训练脚本、实验流程和初步结果分析。实验结果表明，直接 FP4 GRPO 容易出现生成退化和奖励信号不足，而经过量化感知自蒸馏后，FP4 后训练的生成质量和奖励表现均有明显改善，训练过程也更加稳定。后续工作将进一步探索量化感知自蒸馏的训练步数、下游任务性能损失、多数据集上的移动均值偏差 FP4 可行性，以及面向低精度噪声的 GRPO 稳定化策略。
